COMP6441 Security Engineering
End-to-End Client Communication

Requirements
------------
Python 3.12+

Install

pip install -r requirements.txt

Running

Terminal 1
python server.py

Terminal 2
python client.py

Terminal 3
python client.py

Features
--------
- RSA key exchange
- Fernet encrypted messaging
- PBKDF2 authentication
- Multi-client support
- Thread-safe server
- TCP message framing
